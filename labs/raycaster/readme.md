# Запуск
```
bazel run //labs/raycaster
```
# Управление
### Polygons
Добавление вершины - <b>LMB</b>  
Перетащить вершину - <b>CTRL + LBM</b>  
Новый полигон - <b>RBM</b>  
### Light
Перемещение мышью
### Static Lights
Добавление источника - <b>LMB</b>  
Удаление источника - <b>CTRL + LBM</b>  
## Константы
Большинство констант вынесено в utils.h
 + <b>kDefaultWindowWidth</b> - начальная ширина окна
 + <b>kDefaultWindowHeight</b> - начальная высота окна
 + <b>kEpsilon</b> - для сравнения даблов
 + <b>kRotateAngle</b> - угол из условия
 + <b>kNearDiffrence</b> - расстояние между концами удаляемых концов лучей
 + <b>kAdditionalLightSourcesCount</b> - количество источников света для полутеней
 + <b>kAdditionalLightSourceRadius</b> - расстояние между дополнительным и основным источниками света
 + <b>kBorderOffset</b>- чтобы фиктивный прямоугольник не был виден
 + <b>kCaptureRadius</b> - радиус захвата вершины/статического источника
 + <b>kShadowAlpha</b> - для полутеней
 + <b>kTimerRepaint</b> - переключение между вызовами repaint через таймер и по надобности (в этом случае при движении мыши repaint может вызываться слишком часто)
 + <b>kTimerDelay</b> - очевидно
# Из прикольного
 + Зажав ctrl можно перетягивать вершины полигонов в режиме Polygons  
 + Ресайз работает нормально!  
 + Реализовано кэширование всякого статического. Полигоны и статическое освещение рисуется только один раз, т.е. можно натыкать множество статических источников света и режи Light будет работать нормально.
