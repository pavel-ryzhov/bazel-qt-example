# Запуск
```
bazel run //labs/duolingo
```
Сбросить все упражнения к статусу Task::NotDone:
```
bazel run //labs/duolingo -- reset
```
Если вдруг надо проинициализировать базу данных (в репозитории она готовая):
```
bazel run //labs/duolingo -- init
```
# Чутка про функционал
Упражнение состоит из 7 заданий (меньше если не достаточно подходящего типа). На них даётся 3 минуты.  
### Упражнение завершаесля если  
+ Истекло время
+ Допущено 4 ошибки во всём упражнении
+ Допущены 3 ошибки в текущем задании (перевод)
+ Допущены 2 ошибки в текущем задании (грамматика)

Баллы начисляются только если ошибок не было во всём упражнении  
### Звуки
+ Старт упражнения
+ Верный ответ
+ Неверный ответ
### Бинды
+ **H** - подсказка
+ **Alt** - тоже подсказка, просто при переводе H меганеудобно
+ **Ctrl + R** - чит-код для сброса упражнений к Task::NotDone
+ **Return** - submit при переводе
